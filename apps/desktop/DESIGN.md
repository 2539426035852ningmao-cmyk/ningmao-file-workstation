# 候选界面的实现说明

唯一产品设计规范为[根 design.md](../../design.md) v0.3，最新产品决定为[D06](../../docs/product/D06-two-state-shelf-2026-11-16.md)。本文件只记录实现事实。

本轮基于 PR #95 / 17cfb4707d0cd22076bc4f074f8f59f046dec3b4，分支 feat/two-state-shelf-20261116。完整证据见 ACTIVE-DELIVERY 和本轮执行记录。

- Operate 模式，文件内容优先。日常架默认420×520，最小340×320；保留边缘缩放、原生位置/尺寸恢复。
- 小球直接打开完整文件架，取消横向胶囊。右上角一个收起按钮；文件架和入口共享置顶偏好，取消置顶后失焦收起，原生拖放和系统选择器期间保护目标。
- 44px标题行保留当前文件架、添加、更多和收起；下方常驻36px搜索框。更多菜单在本文件架中央打开，轻微虚化背景，沿用Radix焦点/键盘/关闭。
- 白色、深蓝、浅蓝三主题跨窗共享语义变量；等宽数字、同心圆角、均衡标题。常规内容纯平、浮层柔和阴影；短提示代替原生title黑框，保留无障碍名称与完整说明。
- 复用现有Tauri/Rust/React/SQLite、shadcn/Radix、Lucide、虚拟列表和双眼运动控制器。不新建业务平台或动画引擎。
- 继续保留安全引用/复制、任务、预览、多选、排序、标签、回收、互传、AI权限与费用边界。管理中心结构重做另行讨论。
- 交付包提供旧工作区接续与备份后更新；配置/源校验失败不静默转空。源码存在、浏览器/Windows原生/跨设备验证与正式放行分别记录。
