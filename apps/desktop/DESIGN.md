# 主工程界面约束

本页只补充当前候选的实施状态。产品设计以默认分支的 [根目录 design.md](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/blob/main/design.md) 为准，制作顺序见 [roadmap.md](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/blob/main/docs/roadmap.md)；旧候选分支缺少这些文件时先读取 main，不能另建冲突规范。建议尺寸与最终视觉仍待验收。

交互沿用冻结第 6 项：单击选中，空格预览，双击系统默认程序打开；详情从显式按钮或右键进入。上一增量 #21 仅修复该交互；紧凑布局由下述独立候选承载，最终视觉仍待验收。

Issue #15的紧凑布局现进入P0/P1阶段集成：正式窗口与preview共用420×520 / 最小340×320；window-state仅记忆尺寸，仍为待验收建议。单行顶栏、按需操作与视图/筛选保持。卡片直接拖动调用既有原生Copy，六点手柄仅排序；不改SQLite或Copy语义。阶段三尺寸证据见docs/research/P0-P1-stage-evidence，集中清单见docs/stages/P0-P1-windows-acceptance.md，实际OLE与DPI未测。

Issue #23 仅补充每架视图、缩略图和显示排序记忆，沿用既有菜单和错误提示。存储失败明确提示仅临时生效；不是配置迁移、窗口布局或多窗口同步，也不改变设计建议值与原生验收门槛。

Issue #25 在同一更多菜单补充最近修改、类型、大小排序，不新增工具条或改CSS。目录前置按名称，文件自动排序不改手动位置；旧显示设置兼容读取，新增排序使用v2记忆。小窗口沿用Radix滚动、焦点和键盘，不增加常驻面板。

Issue #27 的类型/标签/状态筛选仅从更多菜单进入已有Sheet；原生选择框，关闭后回到文件。活动提示复用语义行，不新增常驻工具栏。隐藏项不能触发预览或移除，筛选不改变手动位置；条件仅临时，不改变设计建议尺寸或正式验收门槛。

模式：Operate。用户已验收 M1-03，并于 2026-10-23 授权按照推荐方案继续。

沿用已比较的 shadcn/ui 深浅色、蓝色强调色、系统中文字体与文件视图；SpaceUI 仅复用 FileThumb，不加载第二套主题/通用控件。文件是主内容，不新增品牌画面或概念方向。

临时架常态显示“仅保存引用”，绑定目录显示“复制并保留来源”。错误不只依赖颜色，失效引用保留名称、标签与路径。默认隐藏详情，窄窗用已验证 Sheet。进度与取消在任务区呈现。复杂 Dock、管理中心与实体删除不在此闭环中实现，43 项完整需求保留。
