# 柠猫文件工作站 · 内部预览

双击 Start-Ningmao.vbs 启动，不弹控制台窗口。若系统没有 Windows Script Host，可使用 Start-Ningmao.cmd。需要 Windows x64 和已安装的 Microsoft WebView2 Runtime。此版本未经签名，不是正式发布版本。

数据保存在本目录的 data 和 webview 中。备份前请通过程序菜单完整退出，再复制这两个目录；不要覆盖旧版本的数据。请将本目录解压到可写位置。

以后更新：先从菜单完整退出，解压新包，双击新包中的 Update-Ningmao.vbs，选择原程序所在文件夹。更新会先备份工作区数据，再替换程序；之后继续从原目录启动，文件架、目录连接、窗口布局和主题设置保留。工作区正在使用或校验失败时会停止更新。备份在原程序目录的 backups 中。

如果要直接从新目录运行：双击 Connect-Workspace.vbs，主动选择原测试包所在文件夹，再启动新包。此操作仅记住原工作区位置，不移动数据库或素材；原目录需要继续保留。没有重新接续时，新包使用独立的空工作区。旧工作区不可用或设置版本不兼容时会提示，不会静默改用空数据。两个入口均有同名 cmd 备用。

管理中心“设置”可导出数据库备份。若程序无法打开，先确保已完整退出，再把导出的 `.sqlite3` 备份拖到 `Recover-Ningmao.cmd` 上，在程序提示中确认恢复。原数据库会保留为 data 下的 before-restore 文件；损坏库保留原始文件，供后续检查。备份不包含原始素材和设备私钥，不会重新下载或找回已丢失的素材。
