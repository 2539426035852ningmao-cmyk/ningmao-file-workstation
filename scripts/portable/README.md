# 柠猫文件工作站 · 内部预览

双击 Start-Ningmao.cmd 启动。需要 Windows x64 和已安装的 Microsoft WebView2 Runtime。此版本未经签名，不是正式发布版本。

数据保存在本目录的 data 和 webview 中。备份前请通过程序菜单完整退出，再复制这两个目录；不要覆盖旧版本的数据。请将本目录解压到可写位置。

管理中心“设置”可导出数据库备份。若程序无法打开，先确保已完整退出，再把导出的 `.sqlite3` 备份拖到 `Recover-Ningmao.cmd` 上，在程序提示中确认恢复。原数据库会保留为 data 下的 before-restore 文件；损坏库保留原始文件，供后续检查。备份不包含原始素材和设备私钥，不会重新下载或找回已丢失的素材。
