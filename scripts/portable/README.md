# 柠猫文件工作站 · 内部预览

双击 Start-Ningmao.vbs 启动，不弹控制台窗口。若系统没有 Windows Script Host，可使用 Start-Ningmao.cmd。需要 Windows x64 和已安装的 Microsoft WebView2 Runtime。此版本未经签名，不是正式发布版本。

新版默认接续最近使用的工作区，保留文件架、引用、主题和撤销历史，不需要每次选择旧包。原数据保留原位置，不要删除原工作区目录。备份前请通过“更多 → 窗口与入口 → 完整退出”结束程序，再备份该工作区的 data 和 webview。请将程序解压到可写位置。

以后更新：先完整退出旧版，解压新包，直接运行 Start-Ningmao.vbs 即可接续工作区。若希望继续使用原程序目录，运行 Update-Ningmao.vbs；它默认使用已记住的程序目录，先备份数据再替换程序。工作区正在使用或校验失败时停止更新。备份在原程序目录的 backups 中。

首次接续旧版本时，优先识别正在运行的便携包，再检查相邻包目录；多份无法唯一识别时才需要定位一次。旧工作区不可用时保留原连接并提供重新定位，绝不自动换成空数据。Connect-Workspace.vbs 可主动切换连接；New-Workspace.vbs 创建独立工作区，不覆盖已有数据。首次全新使用的默认工作区在当前用户 LocalAppData 的 Ningmao/Workspace 中。

管理中心“设置”可导出数据库备份。若程序无法打开，先确保已完整退出，再把导出的 `.sqlite3` 备份拖到 `Recover-Ningmao.cmd` 上，在程序提示中确认恢复。原数据库会保留为 data 下的 before-restore 文件；损坏库保留原始文件，供后续检查。备份不包含原始素材和设备私钥，不会重新下载或找回已丢失的素材。
