# 下一阶段路线图：互传与同步

从「工作01」已验收的 D15 候选出发，接续方式见[开发接续](codex-start-here.md)。下面是实施顺序，候选能力与未交付项见[项目状态](project-status.md)。

| 顺序 | 目标 | 验收重点 |
| --- | --- | --- |
| 1 | 局域网互传与连接恢复 | 两台设备发现、核对、确认收件；断网、取消、重试不会产生重复文件；大小与哈希校验；保留来源。 |
| 2 | 跨网络与多端互传 | 复用现有 WebRTC/WSS 与任务状态；验证不同网络、休眠唤醒、手机和浏览器，明确连接不可用时的提示。 |
| 3 | 账号与设备绑定 | 登录、设备身份和设备撤销分别确认；解绑后及时撤回权限；普通本地工作可继续使用。 |
| 4 | 跨账号分享与同步 | 先做范围明确、可撤销的分享，再考虑持续同步。同步前要定义冲突、版本、删除和离线恢复规则。 |

第一阶段使用合成文件。两台独立 Windows 虚拟机在隔离网段复现的安装版场景可计入双机验收，记录连接方式和实际覆盖范围。保持确认接收、默认不监听和本地文件保护。账号服务、跨网回退、托管成本和同步范围在实施相应阶段前分别讨论。

## 用户怎么用

1. **附近发送**。从文件架选文件，点击「发送到设备」，选择设备后发送。找不到设备时，从同一页转到粘贴连接信息。接收方先选保存位置、开启接收，再同意这批文件。中断后可直接重试未送达项，待核对项先在接收目录确认。双机已验收中途断网、取消及重试后的同名保护。接着复测双向并发。
2. **网页邀请**。在现有临时互传区创建或加入房间，沿用链接和邀请代码。网页入口显示文件可下载时限和供件状态。先验证在不同虚拟网络上从 Windows 发给网页、手机，以及没人供件时的恢复提示，再比较直连和可选回退的实际成本。
3. **指定对象分享与同步**。用户先选范围、对象和有效期，分享页提供撤销入口。持续同步前先明确冲突副本、历史版本、删除传播、断线恢复和撤销后的权限，再验证小范围双向同步。

开源复用与实际试验见[开源项目复用记录](research/P3-P4-open-source-reuse-2026-10-26.md)。

## 互传首版三轮收束

估算以五人文件群、现有自托管 HTTPS 和 Windows 原生局域网为首版范围。扫码互传已获用户确认。浏览器和 Windows 文件列表显示当前群内发件人，两端继续使用各自的保存反馈。[扫码验收](execution/MOBILE-ROOM-SCAN.md)

1. **满员和传输恢复。** 五个独立浏览器会话已完成并发上传、四端同时领取、一端续传、重复领取及落盘校验。原生取消和同名留存沿用已有证据。[并发场景和性能数据](execution/ROOM-FIVE-MEMBER-LOAD.md)
2. **设备与网络闭环。** 桌面已区分本机站点与 HTTPS，断线暂挂，恢复后沿原房间继续。分别记录设备联测、房主停站和在线供件回退证据。[设备与站点恢复](execution/ROOM-DEVICE-RECOVERY.md)
3. **操作与交付。** 网页保留原文件续传，手机提示准备保存，桌面说明收件位置。用统一候选和清单复验，设备证据及待验场景按记录核对。[统一验收](execution/ROOM-FIRST-RELEASE-CANDIDATE.md)

## 账号、好友和文件群

1. **收束临时互传。** 网页与 Windows 统一文件查找与收发筛选，保留访客邀请、审批、定向发送、续传与收件保护。统一 GitHub 的验收状态与候选证据。
2. **建立账号闭环。** 用户在自建站点自行设置独立账号名和密码，网页与 Windows 共用身份，支持改密、退出和设备撤销。首次在已有工作区的 Windows 登录时，可显式关联该工作区或从空白开始。原文件原地保留，本机工作区可离线使用，其他账号看不到已关联的工作区。登录后打开互传邀请沿用当前会话，群内无需再次输入密码。
3. **实现好友、文字和固定文件群。** 通过账号名加好友，对方同意后可直接发文字和文件。重要的群可固定，从好友列表拉人。私聊和固定群的近期文字由自建站点保存，在网页与 Windows 均可查看。文件仍按原时限领取，沿用站点暂存与成员手动供件。
4. **让指定管理员接管。** 群主提前指定一台管理员设备保存接管所需的群记录。主机离线后由管理员显式继续托管，保持单一生效的托管方。完整副本由发件人或主动开启供件的成员保存。验收先覆盖离线接管和群主重新上线后的权限一致性。
5. **统一界面。** 先打磨网页的账号、会话与文件操作，再把同一操作语义落到 Windows。复用柠猫的不间断工作区、控件和主题。按需参考上游交互并使用工具核对窄屏布局、键盘、中文输入和减弱动效。

账号与文件群首版以自托管和已有设备运行，不依赖收费云服务。持续文件同步在定义冲突、版本、删除、离线恢复和权限变化后另行验收。

Windows 正式发行继续遵守 [D-01 发布策略](product/D01-windows-preview-release-policy-2026-10-26.md)。早期路线与验证见[历史索引](archive/README.md)。
