# M1-05 · 真实文件闭环

日期：2026-10-23。Issue #8；承接用户已批准的 M1-04 方案。唯一主工程位于 apps/desktop。

## 实现

- 可移动、可置顶的 Windows 窗口；关闭隐藏到托盘，提供完整退出。
- 原生拖入或主动选择文件：临时架建立真实路径引用，SQLite 保存并恢复；仅本次架只在完整退出时清空引用，异常退出不清空。
- 真实文件名、类型、失效状态与 PNG/JPEG/WebP 限额缩略图；标签与手动顺序保存。失效引用不自动删除，不扫描其父目录。
- 用户通过系统对话框主动绑定目录，只列出直接子项；拖入文件后台复制，来源保留，同名自动编号，原子发布不覆盖。
- 每次只运行一个复制批次，支持字节进度和取消；已完成部分保留，当前未完成暂存文件在正常取消/失败时清理。异常退出保留任务与暂存位置，不自动删除。
- 通过 drag-rs 的 Copy 将已登记的真实文件拖出；IPC 不提供原文件删除/移动或任意 SQL。

## 验证入口

脚本 scripts/build-desktop.ps1 -Native / -Browser。Rust 安全回归、独立浏览器测试构建、原生候选准确哈希与本机验证分别记录于 [M1-05 验证记录](../research/M1-05-verification.md)。

浏览器测试使用单独 tests/harness.html 与明确合成数据，不进入生产 dist；它验证界面和后端契约，不证明真实 Windows 拖拽。真实文件字节/SQLite/复制测试由 Rust 在隔离目录执行。

后台补测已增加真实进程强制终止恢复、Windows 文件占用与复制期间句柄保护、较新/损坏数据库拒绝写入，现有 Rust 安全回归合计 10 项。子进程无窗口、低优先级，并由父测试负责终止/回收；未改产品代码及候选哈希，不启动原生前台验收。

## 边界和回滚

当前不递归复制文件夹；文件夹可作为临时引用添加，绑定目录只浅层浏览。完整目录浏览/递归素材视图、复杂 Dock、跨架操作、管理中心、AI、远程和其余 43 项功能继续保留在后续计划。

原型不是安装版或完整 V0.1。原生关键体验由用户验收；Win10、多屏、其他 DPI、跨软件目标、磁盘空间不足与完整分发合规未完成时明确标记。PR 采用独立功能分支，回滚 revert；不强推、不删除用户原文件或工作数据库，不自动降级较新数据库。
