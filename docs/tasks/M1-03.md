日期：2026-10-23（Asia/Hong_Kong）。用户明确验收 M1-02 并授权继续，跟踪 [Issue #5](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/issues/5)。本阶段不重新规划需求，不批准最终视觉与主工程。

## 交付范围

固定版本 SpaceUI 与 shadcn/ui，共用相同合成数据、1120×760 初始尺寸、信息结构、dnd-kit pointer 排序和 TanStack Virtual。两套组件源码、许可、轻量修改和原始来源逐文件记录。Windows 原生探针沿用已验收 M1-02 后端并隔离测试标识及运行目录。

功能：深浅主题、网格/详细列表/缩略图尺寸、标签页、渐进工具栏、宽窗详情面板/窄窗抽屉、快速预览、搜索、分组折叠、标签过滤、右键和手动排序。500/2000 项分别记录网格/列表采样。真实拖入只记录事件；不冒充正式引用、目录绑定或数据库功能。
