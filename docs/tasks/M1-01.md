# M1-01 · 公开仓库初始化

日期：2026-10-23（Asia/Hong_Kong）。工程初始化记录；产品验收由用户完成。

## 范围

创建并验证公开仓库、Apache-2.0、README、AGENTS、贡献与安全规范、行为准则、第三方清单、43 项需求、M1 任务记录、GitHub 模板和基础 CI；在真实检查项建立后配置 main 保护。

本轮没有应用代码、Windows 安装包或原生文件功能实现，不开始 M1-02。

## 验收步骤

1. 核对仓库所有者、名称、Public 可见性、Apache-2.0 和默认分支 main。
2. 运行 `pwsh -NoProfile -File scripts/check-repository.ps1`。
3. 检查初始化 PR 的 Windows 与 Ubuntu 两项 CI，随后核对合入 main 的运行。
4. 通过 GitHub API 读回 main 保护，确认必需检查名与实际 check-run 完全一致。
5. 核对远程 Git tree、文件 blob、提交 SHA 与本地一致。
6. 只跟踪明确清单中的治理文件；不上传聊天原始 HTML、账号凭据、便携 CLI 或私人素材。

## 保护目标

- main 通过 PR 合并，初始化阶段 0 个强制批准审核，允许单人维护。
- 必需检查 `Repository checks (windows-latest)` 和 `Repository checks (ubuntu-latest)`，要求分支最新。
- 管理员同样受规则约束，禁止强推和分支删除，要求线性历史与对话解决。
- 采用 squash 合并；规则配置与执行结果以最终 API 读回为准，不以本文件的目标声明代替验证。

## 证据

最终 Issue、PR、CI、main 保护读回结果与提交标识在验收收尾时补入本节。若权限不足或检查失败，必须记录具体原因，不能标记成功。

## 回滚

文档和 CI 配置通过新分支及 revert PR 回滚，保留历史。保护规则需经管理员按审查后的具体变更修改；不以删除仓库、强推或清空历史作为回滚。
