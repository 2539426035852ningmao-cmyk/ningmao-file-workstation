- 复用 Tauri CLI 2.12.4 的 WiX MSI 能力；独立预览配置，不修改主应用配置、前端或文件操作代码。

- Node 标准库收集许可原文；PowerShell 调用 Windows Installer OpenDatabase(mode=0) 只读查询。检查覆盖声明原文/NOTICE、越界路径拒绝、额外载荷及用户数据删除拒绝；新增交付完整性检查拒绝改字节、遗漏、重复及越界校验条目，不执行应用或安装动作。
