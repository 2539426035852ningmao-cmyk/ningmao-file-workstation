## S1–S3 实现记录（独立 Draft #36）

- S1：原创左右眼分别阻尼、移动时冻结当前姿态、邻近鼠标采样120ms且不扩大命中区；单个待机定时器/按需RAF；主体5px拖动阈值和点击抑制。修复Radix Portal事件误冒泡到顶栏拖动的问题。轻预览28px圆形双色反馈、胶囊连体小球只有8px红芯激活、顶部吸边改下方且移动中不换锚点。32ms轮廓节流不因持续指针移动饿死。
- S1原生：使用已锁定windows-rs 0.62.2的Win32 region组合轮廓，关闭原生阴影并设置透明背景；透明角落不扩大桌面命中。按可见主体而非透明padding在工作区6CSSpx吸边，支持负坐标和缩放；主体拖离后自由放置。原生拖放期间禁止轮廓、尺寸和位置更新。实际Win10/11黑框/命中/125%/150%/多屏仍待集中实测。
- S2：schema2软回收保留原行/ID/标签/位置；首次建库才创建基础架。整架作为一个回收条目，子引用独立软删状态保留；会话清理跳过已回收项/整架及待核对实体操作。永久清理仅删数据库记录；绑定扫描使用遮蔽记录防止条目复活。单调ID避免永久清理后旧ID复用。全局右抽屉、全架/当前或已回收架筛选、撤销、零架新建/恢复入口，多窗更新广播。记录原窗口布局用于整架恢复，沿用原架ID的本地视图偏好。
- S2迁移：仅对合成schema1做VACUUM INTO一致性快照和integrity_check，再事务升级；备份保留schema1，包含未checkpoint WAL提交。旧r16的Store::open拒绝user_version>1，因此禁止把新库交回旧程序；代码回退不会降级数据库。用户r16目录未触碰。
- S3：独立真实文件回收预览/额外原生确认，限定登记文件/所属窗口、5分钟单次票据、逐项复核文件身份。只支持本机NTFS固定盘普通文件；目录、网络/移动盘、重解析路径、设备流和受保护数据拒绝。IFileOperation使用FOFX_RECYCLEONDELETE，绝无fs删除/永久兜底；父目录句柄保护，PreDelete重验，PostDelete核验回收站目标实体ID和内容。逐项journal先记录意图，OS确认后才软回收发起引用，其它同路径引用保留并变失效；未确认状态保留供人工核对，启动不重试实体操作，已记OS成功只补元数据。
- 首次Shell测试因canonical verbatim前缀返回0x80070057；转换为Shell解析路径后真实系统回收通过。失败未被记为成功。原生回收只操作新建合成文件，无可见候选/Explorer启动。
