# P1 · 当前架组合筛选

2026-10-24，Issue #27，feat/shelf-file-filters，基于Draft #26 `6c4eeb45fb8348fbd7ed7f4dcde400bd123fc5ee`。落实冻结第13/30项的当前架子集，保留43项完整需求与main设计/路线。

## 实际行为

- 更多菜单按需打开已有Sheet，三个原生选择框按文件类型、单个已有标签、正常/异常状态取交集，可叠加现有文件名搜索。选项只来自当前架，不增加索引或扫描。
- 类型使用既有snapshot.kind；缺失或不可读记录可能只有file/未知类型，不从失效路径猜测扩展名。异常包括missing/unreadable/unsupported及未来非normal状态，记录不删除。
- 活动筛选在原语义行显示“已筛选”及清除按钮；无结果时可明确清除筛选/搜索。关闭搜索只清名称查询，筛选仍有提示；切架或重新载入清除临时筛选，显示视图/排序记忆不受影响。
- 标签/类型最后一条记录消失时，当前已选条件保留为选项，明确显示无匹配，避免选择框看似“全部”但暗中仍在过滤。
- 仅当前可见的选中记录可触发详情、预览和Delete；隐藏项暂不参与键盘操作，不会因筛选误移除引用。原搜索也使用同一保护。筛选或搜索期间禁用排序手柄并在drag-end再次防守，清除后恢复原手动位置。
- 筛选只在内存中运行，不保存查询、标签条件或类型到WebView/SQLite，不修改用户文件。保留原有引用/复制语义和原生Copy按钮。

## 复用与实现边界

先核查现有Item.tags/kind/status、过滤/排序和Radix Sheet、当前CSS原生select；比较 [shadcn/ui NativeSelect原始实现](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/new-york-v4/ui/native-select.tsx)（仅阅读，未复制代码）。继续用浏览器select及已有Sheet/按钮/菜单，沿用现有许可，无新增依赖、Rust/IPC/schema或文件操作改动。样式只补三个表单布局规则与活动提示图标颜色，不另设视觉体系。

尚不实现自定义标签编辑、多标签布尔表达式、虚拟分组、Ctrl+K跨架检索、日期/来源过滤或索引服务，不代表第13/30项全部完成。筛选条件不持久化，也不改变#24/#26已有界面设置及数据目录隔离边界。
