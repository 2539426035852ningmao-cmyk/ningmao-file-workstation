## 实际行为

- 每个文件架按已有ID独立保存网格/列表、60/80/120缩略图、手动/名称排序；切换和重新载入时恢复。新架保持网格、中缩略图、手动顺序默认值，不改变默认启动文件架。
- 切换名称排序仅改变显示；原有SQLite手动顺序和文件位置不改写。
- 复用已有主题采用的WebView localStorage，视图键 ningmao-shelf-views 使用 version=1 与 shelves 映射；只存ID和三个选项，不存文件路径、名称、搜索词、素材或凭据。主题仍沿用 ningmao-theme 键。
- 只在用户显式改变视图时写入；启动读取不自动覆盖视图记录。有效条目保留，无效条目默认回退并提示，用户重新选择后可归一化保存。
- 不认识的版本和超过100,000字符的记录保留原文、本次只临时显示，防止旧版本软件将新格式降级覆盖。
- 读取受限或写入配额失败不会使界面白屏，显示调整在内存生效并提示未保存；权限恢复后下一次设置可保存。主题读写也补充异常保护，沿用现有视觉与菜单。

## 复用与边界

没有新增依赖、Rust命令、IPC权限、SQLite schema或复制/拖放改动；使用标准浏览器接口和已有React状态。原始说明见 [WHATWG Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html#the-localstorage-attribute) 与 [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)；实现不复制第三方代码，无新增许可义务。

视图记录属于当前应用WebView的界面偏好，不在现有SQLite数据库备份中；清除浏览器/应用数据会丢失这些显示选项。更改NINGMAO_DATA_DIR不会自动切换WebView存储，若不同数据库复用同一架ID，显示偏好可能复用；文件记录仍来自各自SQLite。配置迁移、按数据集隔离、多窗口实时同步、上次活动架和窗口/DPI布局记忆留后续，不以此增量冒充完成。
