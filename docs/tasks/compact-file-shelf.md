# P1 · 紧凑悬浮文件架候选

日期：2026-10-24。跟踪 Issue #15；独立分支 feat/compact-file-shelf，基于 #21 源码 `ccfe586126e60a9d543c28c997d5932a212ecf6b`。根设计规范 main/design.md（blob `ad73686f8e5ba1380e3730ee72481ff1ee124c6f`）和完整路线继续有效。

## 本轮可操作范围

- 44px 单行顶栏：文件架切换、原位搜索、添加、更多；默认不显示品牌栏、重复标题、独立工具栏、固定 Inspector 或底部说明。
- 轻量语义区持续区分“仅保存引用”和“复制到目录 · 保留来源”；选中后才显示详情与拖出复制，原有独立原生 Copy 入口保留，不把手柄排序当系统拖出。
- 当前架通过 Radix 菜单切换，绑定文件夹在该菜单中；排序、网格/列表、三档缩略图、主题、置顶、刷新、复制任务与完整退出进入更多菜单。没有假装已提供管理中心、Dock、设备或 AI。
- 搜索图标或应用内 Ctrl+F 展开，Esc 清空并恢复搜索按钮焦点；不在 IME 组合输入中关闭，不从对话框/菜单抢快捷键。
- 复制只显示 28px 进度条；用户主动展开任务 Sheet 查看/取消/历史。错误持续显示至下一操作或关闭，短结果提示 4.5 秒后隐藏，保留无障碍状态播报。
- 沿用已选深浅主题、蓝色和系统字体，文件名 13px、次要状态 12px；使用 4/8/12/16 间距与外20/内12/控件8圆角。虚拟列表在尺寸/列数/视图变化时重新测量，避免末项不可达。

## 候选与正式窗口的区别

仅预览配置 tauri.preview.conf.json 使用 420×520、最小 340×320；tauri.conf.json 正式默认窗口配置保持原样，等待真实体验后再决定。640×720 是扩大场景的浏览器验证尺寸，没有设置硬性最大窗口限制；不是一次实现完整桌面布局记忆。

没有修改 Rust 业务命令、SQLite schema、复制计划、文件验证、拖放适配、权限、锁文件或第三方组件原始源码。应用外的文件关联行为仍遵守 #21 的确认与错误反馈。

## 复用与验证

使用已安装的 radix-ui 1.8.1 导出 DropdownMenu（实际锁定 @radix-ui/react-dropdown-menu 2.2.1），MIT；ShelfMenu 只组合现有 Root/Trigger/Portal/Content。焦点、键盘导航、滚动与碰撞处理由成熟组件负责。无新增依赖，研究来源与分发边界见 third-party.md。

修复前新增回归因“更多操作”入口缺失而失败。原有 7 项浏览器回归迁移到按需入口，覆盖内容没有删去；新增 9 项覆盖三尺寸×深浅、搜索焦点、菜单键盘、虚拟列表/缩略图切换、最小窗进度/取消/失败/离线。截图和几何记录使用合成名称、测试专用入口，均不包含用户素材。

首轮检查发现嵌套缩略图菜单指针失效，改为同层三档选项；完成两轮视觉检查后停止润色。最终功能核验额外修复短提示遮挡活动进度的问题：复制中或有错误时隐藏普通短提示，补充短超时回归避免等提示自动消失而误判通过。最终测试与 CI 以 PR/Issue 的提交和运行结果为准，不把任务文档当作运行成功的证据。
