# 双击默认打开与空格预览

日期：2026-10-24。关联 Issue #20、#15，冻结决策第 6 项；基于 #13 源码 `1cfefeaa1a2e33bddb91041d9ead45492c775461`，独立分支 fix/default-file-opening。

## 可验收行为

- 单击只选中，空格快速预览，双击/文件按钮 Enter/右键“用系统默认程序打开”发起系统打开。详情仍从工具栏/右键显式进入。
- IPC 只接受记录 ID，后端重新解析已登记、存在的本地文件/目录；拒绝失效、链接、ADS 等既有不支持路径。确认后再检查引用是否改变/删除，不运行前端命令、URL 或指定程序。
- 常见程序、脚本、快捷方式/安装包需关联调用窗口的原生确认；取消返回 false。扩展名提示不是恶意内容检测，文档和系统处理程序本身仍需可信。
- 系统拒绝时显示错误；成功只表示“已请求系统默认程序打开”，不冒充目标软件已经显示或加载内容。无关联时系统也可能显示“打开方式”，不保证统一错误样式。
- 引用、标签、顺序不改写；文件打开不执行应用内复制/删除。外部默认程序可能修改文件，此行为不受本应用控制。

## 实现与复用

使用 open 5.4.5 的 shellexecute-on-windows，通过 Windows ShellExecuteExW 传递路径，不使用命令行插值/自定义程序/insecure feature。与官方 Tauri opener 相同的底层依赖，不为单个 ID 命令加载整套前端 opener 权限。阻塞平台操作在后台线程完成；等待用户确认时不持有 SQLite 锁。许可及固定来源见 third-party.md。

打开前路径复核可拦截已观察到的替换，不能保证外部进程在最后检查至系统打开之间不修改同一路径；不把这项功能称为内容沙箱或原子文件句柄执行。
