# UI 开发与验收清单

> 适用于所有 UI、窗口、主题、动效和用户流程变更。
> 规范源头：[根目录 design.md](../../design.md)；产品决定：[D05](../product/D05-fluid-workspace-and-theme-contract-2026-11-05.md)；事实审计：[功能与用户流程审计](../audits/feature-and-workflow-audit.md)。

## A. 开发前

- [ ] 先核对最新 main、候选分支、PR 依赖、CI 和当前精确源码 SHA。
- [ ] 明确本次改动解决的用户任务，不只写组件名称。
- [ ] 对照原 V0.1 43 项、P4 44 项和 D05，避免重新询问已确认事项。
- [ ] 标注需求为已确认、代码事实、设计建议或待验证假设。
- [ ] 找出同一功能现有入口、状态和业务服务；优先复用，不复制业务逻辑。
- [ ] 说明会不会改变文件身份、引用/复制、删除、回收、网络、AI、权限或费用语义。
- [ ] 定义成功、失败、取消、中断、恢复和回滚行为。
- [ ] 先核对成熟组件与许可证，不从零重造通用控件。

## B. 三形态与功能归属

- [ ] 悬浮球只承担唤出、拖动、贴边、少量右键入口和文件收集。
- [ ] 横向展开只承担文件架身份/数量/状态、少量最近素材、快速添加/粘贴/拖入、任务摘要、切换和大展开入口。
- [ ] 横向展开没有完整搜索、复杂筛选、完整 AI 对话、完整互传配置或全局设置表单。
- [ ] 大展开承担完整文件浏览、搜索、筛选、预览、标签、批量操作、详情、互传发起和按需 AI。
- [ ] 中展开/QuickPeek 不再作为产品状态；迁移有价值能力前，逐项确认其替代入口。
- [ ] 启动设置只有悬浮球和直接大展开两种。
- [ ] Dock 仍是独立的桌面收纳/切换系统，不作为第四种形态。
- [ ] 管理中心保留独立原生窗口，一级导航只有文件与素材、任务中心、设置。

## C. 窗口与面板

- [ ] 无嵌套 Dialog、Sheet、Drawer 或第二层主要工作面板。
- [ ] 同一工作窗口同一时刻最多一个主要辅助面板。
- [ ] 菜单/Popover 仅承担短时、轻量操作，不成为第二个完整工作空间。
- [ ] 管理中心单实例；重复打开激活现有窗口。
- [ ] 主窗口、独立文件架、管理中心和 Dock 的焦点、置顶、任务栏与关闭行为明确。
- [ ] 关闭/收起 UI 不会意外终止后台任务。
- [ ] 关闭面板后焦点返回合理控件；Esc 行为一致。
- [ ] 窗口位置和尺寸记忆；显示器拔插后可找回；不恢复到屏幕外。
- [ ] Windows 工作区域、任务栏、逻辑/物理像素和多显示器 DPI 计算正确。

## D. Fluid Morph 动画

- [ ] 三形态被实现为连续逻辑状态，而非三个互不相关的弹窗。
- [ ] Orb→Capsule 保留现有流畅度，不发生回归。
- [ ] Capsule→Full 无明显跳位、窗口闪烁、空白帧、突然放大或焦点跳变。
- [ ] Full→Capsule→Orb 沿一致锚点反向收束。
- [ ] Orb→Full 直达时连续经过胶囊几何，不在中间停顿。
- [ ] 位置、尺寸、圆角、裁切、阴影、材质和内容显隐共享同一目标几何/进度。
- [ ] 不存在 CSS 与 Tauri 原生窗口两个独立动画源互相争夺最终尺寸/位置。
- [ ] 动画中再次点击可从当前进度反向或重新定向，不重置到起点。
- [ ] 快速重复触发不会创建重复窗口、计时器或状态竞争。
- [ ] 用户主动拖动时动画让出控制权；释放后才重新吸附/定位。
- [ ] 原生 OLE Enter→Drop/Leave 期间不移动、缩放或隐藏拖放目标。
- [ ] 拖入时反馈不改变命中区域；Drop/Leave 后再展示结果和形变。
- [ ] 文件缩略图不闪烁、不重复解码；文字不突然换行；滚动位置和选择不重置。
- [ ] reduced-motion 下提供简化动画，仍保持状态和焦点清楚。
- [ ] 记录帧时间/窗口几何/焦点事件；不能只凭“看起来不错”验收。

建议测试：连续快速展开/收起至少 20 次；分别测试中断、反向、拖动打断、拖入中断和窗口失焦恢复。动画时长先按 design.md 的建议范围调校，再用目标 Windows 设备验证。

## E. 三套完整主题

- [ ] 主题选择只有白色、深蓝色、亮蓝色三套完整主题。
- [ ] 悬浮球、横向展开、大展开、管理中心和所有功能面板颜色一致。
- [ ] 形态变化不改变主题。
- [ ] 亮蓝色拥有完整背景、表面、文字、边界、选中和状态色，不只是强调按钮。
- [ ] 所有组件使用统一主题 Token，不在组件内硬编码另一套长期颜色。
- [ ] 多个 Tauri WebView 主题切换同步；重启后设置保留。
- [ ] 普通文字对比度目标 4.5:1；重要控件边界和焦点清晰。
- [ ] 强制色彩模式、禁用透明/模糊时仍可用。

## F. 用户流程与业务安全

- [ ] 高频任务尽量 1–3 个主要操作完成；必要的安全确认不省略。
- [ ] 添加文件明确区分临时架引用与绑定目录安全复制。
- [ ] 拖出到文件系统默认 Copy 并保留来源；不意外 Move。
- [ ] 不静默覆盖；冲突默认保留双方。
- [ ] 移除引用、柠猫回收站、Windows 回收站和永久删除语义清楚。
- [ ] 文件夹本地浏览与网络文件夹递归传输范围不混淆。
- [ ] 搜索/预览/详情关闭后保留原文件位置、筛选、选择和滚动状态。
- [ ] 任务状态来自唯一业务来源；UI 收起不终止后台任务。
- [ ] 任务能力按实际支持显示取消、重试、暂停和恢复，不夸大。
- [ ] AI 不静默上传素材、不静默产生费用；真实文件修改有预览、确认、取消和记录。

## G. Windows 原生验收矩阵

每个候选包记录精确 source SHA、build SHA、包 hash、系统版本、DPI、显示器布局、测试步骤和结果。

- [ ] Windows 11 实机，1920×1080，125% 缩放。
- [ ] Windows 11，150% 缩放。
- [ ] Windows 10 实机（若声明支持）。
- [ ] 单显示器与多显示器；不同 DPI 显示器混用。
- [ ] 拔掉当前显示器、重新连接、改变主显示器。
- [ ] 四边贴边展开方向正确，最终窗口完全位于工作区域。
- [ ] Explorer 文件拖入悬浮球/胶囊/大展开。
- [ ] 文件架内部排序、跨架引用复制、拖出到文件夹和创作软件。
- [ ] OLE 拖放期间窗口不移动/缩放/隐藏，Drop/Leave 后正确恢复。
- [ ] 快速重复展开/收起、动画中断和反向。
- [ ] 窗口置顶、任务栏、焦点、Alt+Tab、托盘和完整退出。
- [ ] 减弱动态效果、键盘导航、屏幕阅读器名称和文本缩放。

## H. PR 与回滚

- [ ] 一个 PR 聚焦一个可验收问题；设计文档和业务重构分开。
- [ ] 不直接推 main；保留分支保护和依赖顺序。
- [ ] 运行相关前端/Rust/文档检查；记录未运行的检查及原因。
- [ ] CI PASS 不替代 Windows 原生验收。
- [ ] 未验证项标记 NOT_TESTED/PARTIAL，不继承其他 SHA 的 PASS。
- [ ] 不未经确认删除功能、改数据库 schema、文件安全语义、网络协议或真实数据。
- [ ] 写明风险、回滚点、是否有数据迁移和用户恢复步骤。
