- Ctrl+K 名称、标签、类型搜索；中英文不区分英文大小写；跨架引用按真实文件身份聚合，独立副本保留。主窗/管理中心跨架，独立架由 Rust 限制所属架。

## 复用、限制与回滚

复用本仓库现有 React、Radix/shadcn Sheet/Input/Button、Lucide、TanStack 虚拟列表、rusqlite 和 Windows File ID 原生 API；未新增第三方依赖或复制外部实现，原许可清单仍适用。搜索引擎为简单只读 O(n) 元数据查询，最多显示前 50 个结果；FTS/增量索引、来源/状态筛选表单、断卷时延与规模评估是后续切片，不宣称已有索引。没有文件正文、全盘扫描、模型、AI、插件或网络传输入口。

安全 Copy、多选、手柄排序、默认打开、SQLite 身份和原生拖放源码未改；新导航存在窗口行为风险，仍保持 Draft，禁止自动阶段合并/安装/发布。无 LAN/防火墙/账号/费用操作。P2 稳定 r22 与数据目录保留；回滚退出本实验、使用原 r22 及其原独立目录即可，勿将实验 DB 覆盖用户 DB。


## 2026-10-28：分类、架类型、状态和权限变化

基于 #40 `3ea8419` 普通合并，功能代码 `06825d4d1fcfe50599824259504a165cc3d3f186`。在同一 Ctrl+K 搜索中新增图片/视频/文档/音频/文件夹分类，保留常用格式精确筛选；新增收集架/中转架/绑定目录及正常/引用失效/离线/无法读取筛选，可单独或组合使用。仅显示筛选范围内授权引用；无命中也可按筛选条件查询。Windows 未挂载盘符与网络路径标为离线并避免探测；单个缺失文件仍标为引用失效，实际拔插设备尚未实测。未新增依赖、索引、SQLite 迁移、目录扫描或文件正文读取。

撤销回归：合成硬链接两名称都命中，异步读取后移除最先用于展示的引用，旧代码会保留被移除名称；现保守丢弃该过期结果，再查询可显示剩余引用，避免泄漏旧名称。硬链接分组的匹配引用排序使用集合，避免大量别名二次扫描。过滤与撤权各有确定性红绿测试，Windows 未挂载盘符标记也先红后绿。

本机 Windows11 实机（代码 `06825d4d1fcfe50599824259504a165cc3d3f186`、独立EXE SHA256 `833c3ff7da359a456a4aa1e6ea7e505191e153fa5b7cecb1019527d305a6b1f1`）：Ctrl+K 选择图片→合成图片；状态“引用失效”→失效合成引用并定位到原架；文件架类型“绑定目录”→仅两条绑定架文件，点击编号副本打开正确架并选中。仅新建合成数据，5个保护文件 SHA 不变、5个持久/绑定引用、0任务、schema2 integrity ok；测试程序正常退出。失效引用是预置的独立合成记录，不涉及真实用户文件。独立架冷启动/管理中心原生跨窗、真实拔盘、Win10/DPI/多屏及真实拖放仍未验证。
