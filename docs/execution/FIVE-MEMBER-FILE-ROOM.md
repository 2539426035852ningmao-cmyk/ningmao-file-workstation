# 五人文件群

本增量接续 [房主自托管 HTTPS 与移动端续验](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/pull/115)，沿用 D15 的桌面界面和同一套临时互传站点。

- 每个群最多五名已加入成员，含群主。待批准访客单独显示。满员时，新访客会收到提示，已提交的申请等空位释放后可再批准。掉线、休眠和关闭客户端保留名额。
- 成员可自行退出，邀请仍在有效期时可重新加入。管理员可移出普通成员，群主也可移出管理员。被移出的原会话失去房间访问权限，已保存的文件保留在接收设备中。成员身份基于现有房间会话。
- 老站点升级前若已有超过五名成员，现有成员保留，新成员须等到有空位。新旧客户端配合时，以站点执行的上限为准。现有每群 64 条加入记录的边界继续适用。
- 沿用既有站点启停及文件收发流程。Windows 本机站点仍需显式开启，使用回环地址。

## 可复现验收

- 站点回环同时处理五份待批准申请，只增加四个成员。另验证开放群并发加入、满员提示、退出重新申请、移出及权限边界。
- 独立 Chromium 会话双向收发并对照 SHA-256，验证断线恢复、网页成员与审批显示、主动退出、重新加入、被群主移出。网页界面 18 项、网页单元与站点 44 项通过。
- Windows 界面测试桩验证成员计数更新、取消移出和显式确认。桌面互传界面 22 项、Rust 61 项通过，Rust 按现有配置跳过两项。
- 整包启动按附带的《使用说明》，单机可用桌面和独立浏览器来回测试。两台 Windows 虚拟机和 Android 模拟器已有各自的前序记录。本轮独立保留新的原生、CI 和设备验收结果。

```powershell
npm --prefix apps/web test
npm --prefix apps/web run build
npm --prefix apps/web run test:browser
node apps/web/tests/native-managed-room.mjs "<测试包>/app/Ningmao-Preview-0.1.0-x64.exe" "<隔离测试包>/test-data"
```

原生脚本需要在隔离测试包里先选择并保存「暂存位置」，然后退出预览进程。
