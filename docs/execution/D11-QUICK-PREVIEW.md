# D11 快速预览候选

应用源码：`325261e0b16fdce14fd2a9f82d2c495a58838528`，基于 D10。见 [草稿 PR #101](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/pull/101)。

- 详情向下展开，标题和媒体不跳动；视频播放条从媒体内容中独立，减少动态效果时取消过渡。
- PDF 无需外部程序，使用本地 worker 翻页。DOCX、PPTX、XLSX 读取正文、按文稿顺序的幻灯片文字或表格片段。Office 为简化预览，不保证版式；双击仍用默认程序。
- 文档与视频优先用 Windows 系统缓存的缩略图，缺少缓存时显示类型图标或取视频帧。缩略图仅排队加载可见附近的素材，主动预览不等待缩略图队列，近期大图和卡片可复用。
- 当前文件架按名称与标签检索，保留类型筛选。跨架检索在单次探测批次内共享同路径的文件状态和身份，不扫描新目录、不建立正文索引。

验证：浏览器全量 218 项通过，包含四种文档；最终源码另跑 11 项专项通过，包含新视频卡片和窄窗播放条。Windows Rust 预览 3 项、本地检索 9 项通过，独立 1k/10k 检索规模测试也通过。10k 合成唯一文件在当前机器命中约 1.9–2.2 秒，无命中约 41–44 毫秒；这不是 D10 同条件性能对比。Rust Clippy、格式和仓库检查通过。

Windows WebView2：用与便携包相同的 EXE 在隔离数据目录验证 PDF 实际绘制、原始位置向下展开、DOCX 显示正文、Esc 和正常完整退出；测试库完整性为 ok。视频封面与 PPTX/XLSX 仅有浏览器验证，不扩大为全部 Windows 编码、Office 字体或文档版式兼容。
