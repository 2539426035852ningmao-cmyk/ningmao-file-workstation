## 本机实际效果

工作站默认不开站。「更多操作 → 临时互传区 → 本机互传站点」可选暂存目录和配额，显式启动后填入本机地址。首次开站会收起设置，让创建互传区表单可直接操作。选择父目录只会创建独立的「柠猫互传暂存」子目录。子目录已有其他文件且不属于本站点时，工作站拒绝使用它。

站点只监听 `127.0.0.1:5192`。停站或退出软件后，网页访客暂时无法访问。使用同一目录重新开站，访客可继续用原邀请和原会话领取有效期内的文件。已验证的完整文件保留原到期时间。中断的上传可从已落盘、校验且确认的分块继续。更换暂存目录后，旧互传区仍在原目录。配额限制暂存文件，以预留大小计算。

## 复跑方式

先用 Windows 测试包完成一次「选暂存路径」，选择包里的 `test-data`，然后退出该预览进程。用同包或另一份干净候选的 EXE 启动原生回归。第二个参数必须指向已在预览中配置的独立 `test-data`，脚本会添加合成文件和房间。

```powershell
node apps/web/tests/native-managed-room.mjs "<测试包>/app/Ningmao-Preview-0.1.0-x64.exe" "<隔离测试包>/test-data"
node --test apps/web/tests/managed-room.test.mjs
```

回退时停止并退出本机预览，使用先前的 D15 启动入口。仍需领取的文件可在原暂存目录使用本候选重启。下一步先在隔离虚拟网络验证房主自托管 HTTPS 链路与安卓收发，再决定对外接入和回退方式。
