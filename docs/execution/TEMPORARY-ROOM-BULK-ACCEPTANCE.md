# 临时互传区分块候选

本候选给自托管站点和网页客户端接入分块传输。站点默认只绑定回环地址。运营者设置独立的 ROOM_DATA 和 ROOM_BULK_QUOTA_BYTES 后，网页才使用磁盘暂存，单文件最多 20,000,000,000 字节。未启用时继续使用原来的 64 MiB 网页路径。当前 Windows 客户端的 64 MiB 路径仍可使用。

客户端重选同一文件后通过 SHA-256 核对源，沿用上传编号。站点在分块写入并刷盘后更新 SQLite 偏移，用最终 SHA-256 控制发布。浏览器下载将已确认的范围写入 OPFS，连接恢复后继续请求后续范围，完整校验后才提示保存。浏览器可用磁盘配额决定可接收文件大小。

文件从站点校验发布时开始计算有效期。10,000,000,000 字节以下默认 24 小时，每次延长 24 小时，最多共 72 小时。达到此阈值默认 6 小时，每次延长 6 小时，最多共 24 小时。发件人、群主及群主指定的管理员可撤回或延长。到期或撤回后，站点拒绝新的下载和旧上传任务重新发布。撤回前已发出的响应或已保存的本地副本仍可存在。

## 复测

在 apps/web 执行 npm test、npm run build 和 npm run test:browser -- bulk-room.spec.ts。Playwright 用两个独立 Chromium 会话，分别在上传和下载的第二块注入断网。两侧都从 4,194,304 字节处续传，最终独立核对浏览器保存文件的字节数和 SHA-256。Node 测试覆盖站点重启恢复、未收齐拒绝发布、分块哈希错误、到期拒绝和十进制大小边界。

另可执行 node tests/bulk-room-20gb.mjs STATION_DIRECTORY RECEIVE_DIRECTORY。参数须为现有隔离目录，测试会创建并清理各自的子目录。可使用有足够剩余空间的两个卷，或同一卷至少预留源和目标共 40 GB 及余量。它用合成数据走实际 HTTP、SQLite 和磁盘，上传过半后重启站点，接收端分段写入并从磁盘重新读取计算哈希。

2026-11-19，在 Windows 宿主的独立本机回环 API 会话中实传 20,000,000,000 字节。上传到 10,003,415,040 字节时关闭并重启站点，恢复后返回相同偏移，完整发布后默认保留 6 小时。接收端通过 HTTP 全量保存，并另外通过 Range 逐段复取和落盘。两个文件的重读 SHA-256 均为 `aa55978313222ddd19ce4ee7362f465f8db9b1b6e501ab5c5849e0c5b15dee3c`。这项测试使用本机 HTTP 客户端和实际磁盘。

## 网页成员供件与换源

发布完成的发件人或校验完成的接收者可手动启用供件，关页或停止时退回其他来源。接收端先尝试区内在线、已启用的来源，按站点保存的分块 SHA-256 校验，再写入同一个断点。找不到来源、无法直连或收到坏分块时，自动使用其他在线来源或站点。Android 页面转入后台时停止供件，回到前台可再次开启。

三份独立 Chromium 会话实测使用发件人直连提供第一块，完成的成员接手提供第二块，二者分别停止后，站点仅收到从 8,388,608 字节开始的最后一段请求。接收端完成实际保存并重读 SHA-256。

当前 WebRTC 直连只使用主机 ICE 地址。站点仍提供入区、有效期、撤回、来源发现和分块授权。如果运行站点的设备离线，当前版本无法新建或继续授权。可将站点放在常在线的电脑或 NAS 上。跨网络接管、站点离线后的成员自治、安装版大文件和手机大文件尚待验证。
