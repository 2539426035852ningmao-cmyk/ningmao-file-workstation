# 自托管临时互传区网页验收

[产品方案](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/pull/105)已获确认。本批交付网页小文件流程。站点使用 Node HTTP 或 HTTPS、独立 SQLite 数据目录、同源会话及持久暂存，借用现有 React/Vite、三个主题和文件名检查。区内权限与文件清单直接由自托管服务提供。站点暂存路径参考[启动说明](../../apps/web/README.md)。

| 验收项目 | 结果 |
| --- | --- |
| Windows 本机网页构建与自动测试 | 构建通过，Vitest 29 项和 Node 10 项通过。 |
| Windows 本机 Chromium | 16 项通过。新增用例以实际自托管服务启动两份浏览器配置，甲建区、乙提交申请、甲批准、两个方向分别下载，测试读取保存路径并验证长度和独立 SHA-256。发送者撤回后，对方列表移除文件。 |
| 权限与回执 | API 用例覆盖待批准访客和非成员拒绝读取、双向下载内容一致、发送者撤回、旧文件 URL 返回 404。 |
| 两台独立 Windows 客体 | 待验。当前宿主为 Windows 家庭版，无可用 Hyper-V、现成 Windows 测试客体或已确认授权的本地镜像。微软 Enterprise 评估下载要求注册。 |
| 未进入本次验收的场景 | 安装版互联、手机模拟器、公网 Cloudflare、20 GB 和跨端续传。 |

复测使用同一区的两个浏览器，通过链接或邀请码加入。在两个方向各传一份含中文文件名的合成 TXT。记录两个下载文件的 SHA-256、拒收或批准结果及撤回后旧链接状态。新站点限全区分享，单文件 64 MiB、总暂存 512 MiB。指定成员密文、成员设备供件和文件换源属于后续里程碑。新请求在服务端撤回后立即失效，已开始的响应还可能传完。
