# 柠猫文件工作站 · 初版试用

这是 Windows x64 未签名测试版，非稳定发行版。需要本机已有 WebView2。

## 启动与数据

1. 将 ZIP 完整解压到新的可写文件夹。
2. 双击 `Start-Ningmao.vbs`，默认接续上次工作区，不需要安装 MSI 或每次选择旧包。
3. 原工作区保留原位置；首次全新使用默认位于当前用户 LocalAppData 的 Ningmao/Workspace。备份前从“更多 → 窗口与入口 → 完整退出”结束程序，再复制工作区的 `data` 和 `webview`。
4. 旧版本保留在原目录。回滚时完整退出新版，打开旧版；不要把两个版本的数据库互相覆盖。

## 建议先试这几个流程

- **收集素材**：拖入文件、点“添加引用”，或在资源管理器复制后回文件架按 Ctrl+V。普通收集架只保存引用，来源保留。
- **选择与预览**：单击选择、Ctrl 点选、Shift 连选、空白框选；Space 居中预览图片、文本及可播放的音视频。音视频手动播放，空格播放/暂停，Esc 关闭并停止；不支持的类型可用默认程序打开，双击打开语义保留。
- **工作区接续**：新版自动沿用最近工作区；旧位置不可用时保留连接并提示重新定位。主动切换用 Connect-Workspace.vbs，另建独立工作区用 New-Workspace.vbs，不会覆盖旧数据。
- **任务栏与托盘**：仅管理中心显示任务栏图标，最小化时保留；小球、文件架和预览不占任务栏，系统托盘入口保留。
- **复制与整理**：卡片拖出执行 Copy；六点手柄调整顺序。绑定目录的文件架拖入会安全复制，同名自动编号。
- **文件架名称**：点左上角架名 → 当前架右侧铅笔 → 保存名称。只改显示名称，不改文件夹或素材。
- **撤销与重做**：标题栏两个箭头或 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z。仅撤销文件架内整理，不撤销磁盘复制或 Windows 回收站操作；输入框优先使用文字撤销。记录跟随工作区保存，默认共用 100 步，设置中可调至 1—1000 步。
- **搜索和管理**：Ctrl+F 搜当前架，Ctrl+K 跨架搜索；打开其他工作面板时，先 Esc 关闭再搜索。管理中心分为文件与素材、任务中心、设置。
- **全局主题**：右键标题栏表情选择白色、深蓝色或浅蓝色，也可打开设置选择应用主题。入口和功能面板同步使用同一套主题。
- **悬浮入口**：点小球直接展开文件架；点表情或右上角收起按钮收回小球。两者共享位置，移动任意一个会同步另一个的位置。默认置顶；取消置顶后失焦自动收起，原生对话框和拖放期间保留展开。
- **分组菜单**：顶部三点在文件架中央打开面板，分为常用操作、显示与整理、工具与记录、窗口与入口；底部设置和帮助可用，账户与升级是预留入口。
- **局域网互传**：①接收电脑打开“文件互传 → 接收文件”，选择保存文件夹并开启接收；②发送电脑选中文件，使用“发送到设备”选择附近电脑，首次连接核对六位设备码；③接收电脑确认批次。通常无需填地址，找不到时可复制一次连接信息。发送页会短暂搜索附近设备，接收需主动开启；真实双机/防火墙可达性仍待验，不保证所有网络环境可用。
- **本地整理**：管理中心 → 素材，选中后生成本地规则建议，再点“添加”确认内部标签。建议区可停用规则；已添加标签保留。“撤销本次添加”仅撤销本窗口最近一次规则添加，不移除素材原有标签。
- **AI 对话**：更多菜单打开 AI，进入“配置模型”填写兼容服务，或选择 Anthropic 官方地址建议（https://api.anthropic.com/v1）。模型 ID 以服务方实际可用名称为准，本机示例端口可修改。密钥由 Windows 保护；测试连接和发送消息会请求所配置服务，可能收费。网页会员不等于 API 额度，未配置不会调用。真实模型和费用状态由服务配置决定，本次未代为验证。

## 当前边界

此核心便携包不附带尚未清关的浏览器分享组件，相关入口默认隐藏。本机浏览器分享的原生下载/取消已有独立开发验证，尚不是可分发的跨设备、手机或互联网能力。

多 DPI、多屏、安装升级/卸载、真实双机及真实模型仍未完成完整验收。遇到问题可记录操作步骤和提示文字；不要发送私人素材、API Key、登录码或完整数据库。

文件复制和互传以任务终态为准。失败或取消后先核对任务与目标，不反复点击重发，不手动清理不明暂存文件。移除引用不等于删除来源文件。
