# 柠猫文件工作站 · 初版试用

这是 Windows x64 未签名测试版，非稳定发行版。需要本机已有 WebView2。

## 启动与数据

1. 将 ZIP 完整解压到新的可写文件夹。
2. 双击 `Start-Ningmao.cmd`，不需要安装 MSI。
3. 数据保存在同目录 `data`、`webview`。备份前从“更多 → 完整退出”结束程序，再复制这两个目录。
4. 旧版本保留在原目录。回滚时完整退出新版，打开旧版；不要把两个版本的数据库互相覆盖。

## 建议先试这几个流程

- **收集素材**：拖入文件、点“添加引用”，或在资源管理器复制后回文件架按 Ctrl+V。普通收集架只保存引用，来源保留。
- **选择与预览**：单击选择、Ctrl 点选、Shift 连选、空白框选；Space 预览、Esc 关闭，双击用系统程序打开。
- **复制与整理**：卡片拖出执行 Copy；六点手柄调整顺序。绑定目录的文件架拖入会安全复制，同名自动编号。
- **文件架名称**：点左上角架名 → 重命名当前文件架 → 保存名称。只改显示名称，不改文件夹或素材。
- **搜索和管理**：Ctrl+F 搜当前架，Ctrl+K 跨架搜索；打开其他工作面板时，先 Esc 关闭再搜索。管理中心分为文件与素材、任务中心、设置。
- **全局主题**：管理中心“设置 → 应用主题”选择白色、深蓝色或亮蓝色，也可在文件架“更多 → 显示与排序”中选择。入口和功能面板同步使用同一套主题。
- **悬浮入口**：圆球点一次展开胶囊。点“+”选文件，点剪贴板图标粘贴；点最近素材在完整架中选中，按 Space 预览。点架名打开完整架，“切架”打开其他架，Esc 收回圆球。
- **局域网互传**：①接收电脑打开“文件互传 → 接收文件”，选择保存文件夹并开启接收；②发送电脑选中文件，使用“发送到设备”选择附近电脑，首次连接核对六位设备码；③接收电脑确认批次。通常无需填地址，找不到时可复制一次连接信息。发送页会短暂搜索附近设备，接收需主动开启；真实双机/防火墙可达性仍待验，不保证所有网络环境可用。
- **AI 对话**：更多菜单打开 AI，进入“配置模型”填写兼容服务。密钥由 Windows 保护；测试连接和发送消息会请求所配置服务，可能收费。网页会员不等于 API 额度，未配置不会调用。真实模型和费用状态由服务配置决定，本次未代为验证。

## 当前边界

此核心便携包不附带尚未清关的浏览器分享组件，相关入口默认隐藏。本机浏览器分享的原生下载/取消已有独立开发验证，尚不是可分发的跨设备、手机或互联网能力。

多 DPI、多屏、安装升级/卸载、真实双机及真实模型仍未完成完整验收。遇到问题可记录操作步骤和提示文字；不要发送私人素材、API Key、登录码或完整数据库。

文件复制和互传以任务终态为准。失败或取消后先核对任务与目标，不反复点击重发，不手动清理不明暂存文件。移除引用不等于删除来源文件。
