## 已确定，勿再次反复访谈

- 圆球只有两只不对称小眼睛；无猫/嘴/耳/装饰，动画低频克制。
- 暖白 / 哑光深蓝黑 / 主题蓝三种皮肤，用户独立选择，与软件深浅主题无关。
- 首击圆球到胶囊、次击胶囊到轻预览，明确打开完整文件架。
- 预览/完整窗左上**只有双眼作为非交互品牌标识**；右上角**独立收起按钮**，回对应球/Dock 节点。
- 左右竖 Dock、上下横 Dock、自由悬浮紧凑且尊重手动布局；多架可拆合。
- 不破坏引用/绑定 Copy、原生拖拽、SQLite 与已有 43 项产品决策。
