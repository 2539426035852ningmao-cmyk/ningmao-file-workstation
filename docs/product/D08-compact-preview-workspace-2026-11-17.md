# D08 自动接续、紧凑菜单与内容预览

用户通过《修改需求02》及逐项问答确认本轮方案，并于 2026-11-17 明确批准开始实施。基线为 D07 / PR #97 / 7d1830e。其他来源保护、真实 Copy、窗口位置和持久历史合同保留。

- 新版启动默认接续最近工作区，保留文件架、引用、主题和撤销历史，不让用户每次选择旧包。明确的独立工作区或旧连接优先；首次旧版本无登记时只检查正在运行的便携包和相邻一级包目录，禁止全盘扫描或按修改时间猜测。无法唯一识别时定位一次；旧位置不可用时保留连接并提示重新定位，禁止自动转空库。
- 记忆连接放在当前用户的 Ningmao/workspace.json，支持显式隔离注册表路径用于合成测试。原数据留在原位置；新包可直接启动，不要求搬库或安装。提供 New-Workspace.vbs 独立工作区入口。原更新流程仍先备份、锁定工作区、校验程序后替换，不更改素材。
- 三点菜单保留分组和底部入口，整体缩小、统一尺寸，只让内部内容按需滚动。账户与升级仍为明确预留，未实现身份或支付服务。
- 移除文件架选中态的“详情”“拖出复制”两个按钮；实际卡片拖出复制、右键信息和异常引用修复保留。空格打开居中内容预览；图片看大图、文本可阅读、音视频手动播放；不支持或解码失败时显示文件信息及默认程序打开入口。音视频内空格播放/暂停，Esc 关闭并停止；输入和 IME 不抢键。
- 预览仅接受当前窗口授权的登记项 ID。文本只作为文字显示（包括 HTML/SVG），不嵌入活动文档；文本前 1 MiB、图片沿用受限解码至最长 1600px，音视频通过窗口所有的随机入口按段读取，关闭释放，不启动网络监听、不引入播放器依赖。系统解码器不支持时保留真实失败及外部打开入口。
- 小球内部使用对应文件架主体底色，三主题同步。小球、文件架、拆出架、预览不显示任务栏图标；管理中心显示，最小化保留，关闭消失；托盘入口保留。
- 菜单及预览背景虚化由 3px 调至 1.95px，降低约 35%；输出按窗口 20px 圆角裁切，外层浮层阴影留足物理余量。内容容器内部滚动，不全局放开裁切。

## 复用与来源

沿用 Tauri 2.12.5、Rust 标准库、现有 Store / SQLite 登记和窗口范围校验、Radix Dialog / DropdownMenu、HTML 音视频控件及现有受限图片解码，无新增生产依赖。按需范围响应机制参考 Tauri 官方 streaming 示例：[f9ed1a3](https://github.com/tauri-apps/tauri/blob/f9ed1a3fd303135df26917ad20ce6eec30b601fc/examples/streaming/main.rs)，MIT / Apache-2.0；本项目使用自有窗口授权和有界单段读取，不复制下载示例、无任意路径/远端 URL 接口。UI 继续沿用已选 desktop-agent-ui 规范与项目设计令牌。
