# D06 文件架双形态与保留工作区更新

状态：用户逐项讨论并完整确认，2026-11-16。开发基线：PR #95 / 17cfb4707d0cd22076bc4f074f8f59f046dec3b4。本记录只表达已确认需求，实现与验收证据另行记录。

1. 小球单击直接打开完整文件架，取消横向胶囊。右上角只保留收起按钮，点击回到小球；系统关闭请求遵循同一语义。边缘缩放保留，记忆位置和尺寸。
2. 文件架与小球共用置顶偏好，默认开启。置顶保持展开；取消置顶后切换到其他窗口自动收起。原生文件拖放与系统选择器期间保护目标和父窗口，收起不终止后台复制。
3. 文件架名称与主操作保留在顶栏。搜索框在标题下方常驻，点击输入，Ctrl+F 聚焦；Escape 清空搜索。定位结果时清除妨碍目标显示的筛选，普通重新打开同一架保留当前工作上下文。
4. 顶部更多操作在文件架中央打开，背后内容轻微虚化。沿用键盘导航、Escape、外部点击关闭与回焦，不新增原生菜单窗口。
5. 纯图标按钮保留延迟出现的简短柔和提示，不带标点。移除浏览器原生 title 黑框，必要完整信息通过无障碍描述、文件详情和显式确认表达。
6. 白色、深蓝色、柔和浅蓝色三套完整主题共享布局和控件。等宽数字、同心圆角、均衡标题换行、模块轻微错峰入场，支持系统减少动效。暗背景下小球与文件架边缘清楚。
7. 指定规范为 Ludi-Herry/desktop-agent-ui，固定参考提交 1b48852de665b570b56cc381bab9e565e9884222，MIT。规范没有组件模板，不替换现有 shadcn/Radix。普通工作面板保持平整、必要分隔极细；柔和阴影用于原生窗口与真实浮层。没有复制其上游参考产品的代码或资产。
8. 新包更新接续原工作区，不逐个重新连接目录。更新先备份数据、只替换程序；新目录可主动选择旧工作区并记住位置。旧工作区不可读或配置不兼容时停止，不静默创建空配置替代。原素材与数据目录不搬迁、不覆盖。
9. 本轮处理启动控制台黑窗、文件架布局与双形态、主题和提示、更新接续。管理中心整体结构重做留待后续；本轮只同步共享主题与置顶设置的含义。
10. 用户补充截图确认：移除日常文件架的静态“仅保存引用”提示及空白占位；操作反馈与文件处理语义继续通过相应动作表达。网格内图标、文件名、文件类型共用居中轴线，统一间距；长文件名省略、原视图尺寸与列表语义保留。

本决定取代 D05 中 Orb → Capsule → Full、横向展开功能、旧亮蓝主题表现，以及原第19项关闭隐藏到托盘的相关呈现。其他文件安全、任务、权限、网络和独立管理窗口合同保留。

验收包括原生反复展开收起、失焦/置顶、缩放恢复、系统选择器、中文输入、拖放、三主题与工作区升级。浏览器检查、Windows 原生检查、跨设备与正式发行分别记录，不互相代替。连续物理形变不得仅凭 CSS 或源码存在宣称已原生通过。
