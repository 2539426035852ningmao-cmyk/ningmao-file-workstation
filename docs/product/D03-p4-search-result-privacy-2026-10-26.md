## 1. 已确定的体验策略

**默认轻量结果**：结果列表可以展示当前已授权文件的**文件名、类型、所属文件架和匹配状态**（例如“名称匹配 / 标签匹配 / 内容匹配”），以及与已确认 P4 筛选功能一致的简洁状态。默认**不直接暴露正文命中片段、可识别的文档摘要、完整磁盘路径或离线缓存敏感片段**。

**用户主动展开**：只有用户明确点击“查看命中片段”“查看路径”等上下文操作时，才针对该文件和本次请求**重新检查当前有效授权**，之后以局部折叠内容或管理中心按需预览显示正文命中片段/完整文件路径；授权不足、已撤销、引用失效时不展示并说明原因。不通过仅用 CSS 隐藏敏感文本的方式假装保密。

**不同场景同样适用**：双眼球、贴边柄、轻预览、托盘、系统通知、任务提示和初始搜索结果列表不能默认显示私人正文或完整路径；键盘导航、屏幕阅读器/悬浮提示及复制行为也不能在未经展开和权限验证前泄露这些数据。

**细节保护**：展开后内容属于用户主动查看行为，不承诺能阻止外部屏幕录制/旁观；应支持再次收起，避免在切换文件架或离开搜索时保持无关文件的正文展开。不得将正文/完整路径写进不必要的调试日志、崩溃报表、遥测或通用通知；若确需排障，先脱敏并取得必要授权。

**最小数据处理**：搜索正文仅限用户已授权文件架/目录；展示层的收起不代表允许默认 OCR、全盘扫描或云端上传。撤销目录权限后要使对应派生正文索引、结果缓存、已展开敏感片段不可再访问并按既定安全缓存策略清理，同时**保留合法的用户确认标签、虚拟名称、分类与仍有效的文件架引用**。

## 2. 搜索结果示意（设计规范，不是软件截图）

- 普通结果行：📄 项目合同.pdf · 文档 · 合作资料架 · **内容匹配**；不展示“金额 500 万”等正文片段，不展示 `C:\Users\...\合同.pdf`。
- 用户明确点击“查看命中片段” → 重新校验该文件访问权限 → 展开必要上下文片段。
- 用户明确点击“查看文件位置/完整路径” → 重新校验授权 → 按需提供路径；普通 UI 不常驻路径文本。
- 设备离线：可以展示允许保留的文件名/状态，但不能默认将缓存正文/完整路径作为离线摘要继续展示。
- 失效或已撤销：不展示正文、路径、过期高亮片段，提供重新授权或引用恢复的正常入口（不得自动索取新目录权限）。

## 3. P4-A/P4-B 最小工程验收

- [ ] Ctrl+F / Ctrl+K 搜索首页结果只展示四类轻量字段，不渲染可识别的正文摘录或完整路径（包含提示、辅助文本与复制行为）。
- [ ] “内容匹配”提示能让用户知道匹配来源，但不会将敏感词周围上下文作为默认结果。
- [ ] 用户主动展开后，仅返回当前获准资源的有限命中片段/完整路径；未授权直接拒绝并不向 UI 注入数据。
- [ ] 撤销授权后，已经展开的内容立即关闭或失效；旧请求、缓存、异步结果、离线索引不得再次泄露正文。
- [ ] 隐藏/展开的 UI 经过深浅主题、键盘焦点、屏幕阅读器与窄窗验收；小文件架不因敏感字段增加第二套持久 Inspector。
- [ ] 索引构建、缓存与删除边界与 P4 第02、15、19、24、27、28项兼容，不因隐私要求损坏用户已确认标签或真实文件。
- [ ] 用合成 PDF/文档、同名文件、多架引用、外接盘离线和撤销授权进行 Windows 实机回归；任何测试记录不收集用户私人内容。
