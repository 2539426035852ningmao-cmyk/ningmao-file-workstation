# D-01 · Windows 首个公开测试版与稳定版发布门槛

> **决策状态：CONFIRMED · 用户于 2026-10-26 明确选择 A「分阶段发布」。**
> 决策记录：[GitHub Issue #43](https://github.com/2539426035852ningmao-cmyk/ningmao-file-workstation/issues/43) · [未决项登记簿](../open-decisions.md)。
> **这是一份发布政策，不是现在就能发布的许可、正式稳定版声明、安装行为或发行产物。**
> 与原 V0.1 43 项冻结要求及 P4 独立 44 项决定并存，不代替已有 Windows10/11 长期支持方向。

## 1. 用户已确定的选项

**选择 A：分阶段发布。**

- **公开 Preview：** P2 核心真实文件安全和指定 Windows 11 x64 原生验证通过后，可向明确知情、自愿参加的测试者提供**仅限 Windows 11 x64、未签名、明确标注测试预览版**的候选。不得将「CI 通过」或「有可运行 EXE」作为允许公开的全部依据。
- **稳定 Release：** 不自动随 Preview 发布。面向外界宣称支持的平台，必须完成对应的 Windows 原生兼容与安全验收；默认长期目标仍为 Windows 10/11。还需完成实际安装、升级、卸载、回滚与既有数据保留测试，关键 DPI/多屏/托盘/窗口/拖放/回收矩阵，以及代码签名与分发信任策略审核。
- **Win10 未测不宣传：** 如果没有 Windows 10 真机或等效可信的原生证据，不得使用“Win10 已验收”字样。未来如确有必要缩小首个稳定版的平台范围，须另行说明原因并征得用户确认。
- **费用和签名：** 审核签名/Windows 信任提示方案不代表现在就必须购买证书或新增费用。任何付费签名、托管发布渠道或第三方收费服务必须提前明确费用和授权。
- **正式发布/高风险合并仍有单独门槛：** D-01 只决定**何种发布节奏可以考虑**，不允许跳过 P2 原生/数据安全 R3、仓库保护与明确发布授权。

## 2. Preview 首次公开前的必备验收单（由 Codex 提证）

- [ ] 确认本次目标只为 **Windows 11 x64**；写明准确构建系统版本、DPI、可用显示器和已覆盖的场景，不对未验证环境作保证。
- [ ] 同一个精确源代码 SHA / EXE/MSI SHA256 对应当前用户可拿到的文件；包可以可重现地获取，校验通过；依赖/许可证/构建来源清楚。
- [ ] 对临时引用、真实绑定架安全 Copy、同名不覆盖、双击打开/Space、原生拖入拖出、系统回收/软回收、架恢复和跨架引用一致性至少进行必要真实 Windows 核查；不得使用 r19 的单项 PASS 代替新候选全项。
- [ ] SQLite schema 2、WAL、一致性备份、旧数据兼容和候选失败/退出恢复通过适用的原生与合成回归；用户原始素材和已有工作数据不会被清空、覆盖或隐式物理删除。
- [ ] 任务进度与取消终态、快捷键冲突处理、托盘/窗口找回、正常/非置顶遮挡等核心交互有实机证据；仍 FAIL 的文件安全项必须修复，重大未测/限制写入公开说明。
- [ ] 隔离的合成目录演练安装/退出/重启与数据恢复策略；未签名的 Windows 安全提示不得通过劝用户长期关闭系统防护来“解决”。
- [ ] 编写双语或中文可读的 Preview 发布说明：**非稳定版、未签名、仅 Windows11 x64 目标、已知限制、是否支持安装、反馈渠道、校验值、回退方法、数据备份建议**。
- [ ] 合规/安全门槛、保护分支检查、原生验收及**独立的发布批准**全部完成；否则保持 Draft/候选状态。

## 3. 正式稳定版的额外 Gate

1. 首先决定并验证**实际宣称支持的 Windows 系统与架构**，默认按产品路线 Windows10/11 目标推进；没有完成的系统必须明确排除，缩小范围要另行确认。
2. 完成安装、升级、卸载、用户数据迁移/保留、安全恢复和实际回滚；Git 回滚**不等于** SQLite 数据库降级。
3. 真实 Windows 多 DPI、多显示器、托盘/快捷键、前后台切换、原生拖放/复制、回收与异常恢复均覆盖发布范围。
4. 完成软件源/二进制对应性、第三方许可证、分发信任/签名策略、风险披露、缺陷阻塞等级和最终人工批准。
5. **不会因为首个 Preview 通过，就自动将代码标记 stable 或创建正式 Release。**

## 4. 实施与审核关系

- **当前实际开发状态（2026-10-26 快照）**：P2 r21 候选在 PR #40，CI SUCCESS、Windows 原生矩阵 PARTIAL；功能堆叠 #30→#32→#35→#36→#40 未全部合入 main，仓库尚无正式 Release。
- **D-01 不变更 P2 验收优先级**：先 P2 安全与稳定，再决定 Preview 的具体发布时点；P3/P4 继续按主路线依次推进。
- **与未来两种版本的关系**：如果已有版本决策规定正式安装版、便携版等顺序，仍照原决策执行；D-01 不凭空承诺 Preview 必须同时提供 MSI 和便携包。
- **审核记录形式**：每次候选记录 PASS / FAIL / PARTIAL / NOT_TESTED、测试系统、精确 SHA、未测风险、回滚方法、用户审核结论。只在范围和证据一致时作出产品发布声明。

## 5. 未改变的事项

本决策**不**批准：擅自合并高风险 P2 PR、发布/签名/安装程序、改变 GitHub Release 状态、访问私人素材、修改用户数据库、开设公网/LAN 监听或调用付费云模型。上述行为仍走对应专项权限与阶段门槛。
