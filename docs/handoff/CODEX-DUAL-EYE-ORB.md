## 用户已冻结的视觉与交互决策（不可反问或私改）

- 形象只有**完整正圆 + 两只简洁不对称的眼睛**，没有猫、猫耳、嘴、五官装饰；动感来自眼睛和形变。
- 三色**用户独立选择并记忆**，不跟随应用浅/深主题：暖白 `#F5F3EF`、深蓝黑 `#191E28`、品牌蓝 `#2869D6`。深蓝黑无常驻描边、径向鼓光、镜面反射与外圈发光，要求**哑光、平面、极简、高冷**。
- 首次点击圆球：延展为胶囊，眼睛保留在左端。第二次点击：显示轻预览。点击明确「打开文件架」进入 L1 完整文件架；熟练用户另有快捷直达，不强制多次点击。
- 轻预览、完整文件架只在左上角保留小眼睛标识；**眼睛仅动态品牌装饰，不是按钮**。不得接管关闭/收起；键盘不误聚焦。
- **L1 右上角专用收起按钮**，自然回到**该架自己的**独立球/对应 Dock 节点，不是退出进程、不是丢记录。
- 智能混合 Dock：左/右贴边为竖向，上/下为横向，自由悬浮保留手工排布；多个架独立身份、位置、素材、标签、视图，可拆可合；活动架可以动态，非活动架尽量静态。
- 独立管理中心按需打开，小文件架默认 420×520、最小 340×320，单行顶栏，不常驻左导航/右详情/重复品牌标题。
- Windows 真实文件安全永远比动画优先：临时架仅引用；绑定架安全 Copy、不覆盖来源与已有文件；拖出默认 Copy；原生拖放过程中目标 shelf ID 冻结。

## 第 1 阶段：原创双眼 SVG 与 Motion Engine

独立编写有测试的视觉组件（名称可调整）：`OrbFace`、`OrbMotionController`、`OrbSurface`、`AppearanceSettings`。

- 使用自有原创曲线，眼睛大小/开合/注视和身体尺寸解耦；不要复制 Grok 的坐标库/复刻资源或 Emotion Ball 的引擎/表情参数。
- 支持 `idle / gaze / blink / press / opening / working / success / error`、优先级仲裁与取消中断；高频 pointer 不引发 React 全树重渲染。
- 默认低频眼睛动效，单一节能的刷新策略，可见性停止，无无界定时器/监听泄露。
- 球色独立持久化，主题独立运行；普通情况下没有光晕或可见描边；有键盘焦点时仍需可访问的必要焦点视觉。
- 先完成球、胶囊和三款颜色的可交互 Demo 与深浅主题快照，并用测试验证。只在样机通过后接原生窗口。

## 第 2 阶段：轻预览 + 完整窗双眼标识

- 采用已有组件系统 shadcn/Radix/Lucide；不引入第二套 design system。
- 球→胶囊→轻预览：相同双眼有稳定几何关系，容器先伸展、内容随后出现。不要随便硬切 3 个互不关联的弹窗。
- 轻预览最多 3 个最近文件卡片、架名/数量、右下明确「打开文件架」与安全语义；空状态/失效/复制中都有可读文字。
- L1 左上角为**两只无交互眼睛**，右上有独立收起按钮，其他控件遵循单行 44–48px 顶栏。双眼不跳动、不诱导点击、不遮挡名称。
- 可保留原生窗口独立生命周期，以位置对齐 + 内容过渡表达连续性；**不为动画改变真实文件 Drop 接收区域或增添宽泛 IPC 权限**。
