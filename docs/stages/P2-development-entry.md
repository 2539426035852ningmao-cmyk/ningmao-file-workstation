## 实施切面与第一份可运行候选

1. 先新增Rust桌面控制层，管理同进程orb与main；使用Tauri既有WebviewWindowBuilder、show/hide、start_dragging、set_position/set_size/set_always_on_top、Monitor.work_area/scale_factor。当前Cargo.lock固定tauri2.12.5，本机该版本源码已逐项查到，不需新窗口框架。
2. 先定义并测试展开/收起、拖动中不收起、投放目标锁定、负坐标显示器/DPI纠偏和断屏可见恢复。集中运行候选证明真实原生窗口存在，不用CSS圆球冒充系统入口。
3. 沿用Store新增架与跨架仅引用操作，验证失败事务无半写入；目录目标仍走既有安全Copy任务，不复用任意路径IPC。文件内容、标签、顺序和退出恢复一起回归。
4. 收起架聚合到基础Dock，点击恢复目标架；原生drag enter只展开，不在enter导入；仅drop一次导入确定目标。延迟隐藏期间保持接收窗口，不能中途销毁OLE目标。
5. 贴边/自动隐藏、自由拖动与置顶开关、位置/显示器恢复、关闭到托盘/完整退出形成同一候选。管理中心按需打开，先接总览/素材/标签/搜索/任务/简单设置；未来设备/AI显示明确不可用状态，不造假交互。

全部使用同一Runtime与Store，不增加第二套复制实现或后台磁盘扫描。窗口角色/target-shelf须Rust验证；capability按具体label列举，不使用通配远程来源或任意文件路径权限。全局快捷键只在用户设置时注册，冲突可报告，不改系统快捷键。

## 集中验收与边界

orb点击展开 → 实际拖入合成文件 → 整理/复制 → 收回 → 拖近安全展开 → 投放 → 多架Dock再展开 → 完整退出重启恢复；125%/150%及多屏分别记录。自动状态测试和浏览器测试不代替这条原生链路。验收前仅后台编译、无头和CI，不启动窗口。P0/P1文件安全批准与P2窗口/视觉批准分别记录，不自动合并高风险代码。

成熟来源：现有Tauri2.12.5 API及官方window-state2.5.0（许可见docs/third-party.md）；已核对的Holdem3.1.1/MIT原生窗口研究见docs/research/M1-02-comparison.md，原CopyOrMove、单架互斥、失效引用过滤不适用于本产品，不原样引入。此次无新增依赖和上游代码复制，窗口API复用既有锁定版本，shadcn/Radix/Lucide复用已有组件及许可。

## 首个候选的实际边界

已实现：用户命名persistent/session架；跨架引用事务保留源、标签及目标已有项，缺失ID整批回滚，bound目标拒绝；独立原生64px透明窗口承载48px入口，收起架聚合为每页5架基础Dock；拖动柄移动；点击按确定ID展开到现有main。native Enter/Over只唤出不导入，Drop消耗一次冻结的页内ID，Leave取消；拖入期间拒绝翻页、收起和主动切架。目录投放走原Copy任务，来源保留、冲突编号/活动任务保护继续沿用。

布局desktop-layout-v1.json仅保存架ID、展开/收起、分页和位置；临时文件＋sync＋persist替换，损坏/未来版本原件保留且只用临时状态。位置在显式收起/展开/翻页/完整退出时保存，移动事件只更新内存。断屏时纠偏到可用工作区；负坐标/小工作区算法已测，真实多屏/DPI尚未测。窗口权限只列main和desktop-entry，文件命令Rust核对main，不增加远程来源或路径权限。

当前只有一个展开主架窗口，多个架可收纳到Dock；不是多架并列展开。入口默认关闭、首个收起时启用；可在主架菜单关闭入口并恢复主架，不能冒充智能聚合设置。原生拖近后主架保持展开，不执行未经验证的延迟隐藏；贴边吸附/自动隐藏、每架独立展开窗口、独立管理中心、任务状态点、入口置顶切换仍未完成。完整退出/托盘/尺寸沿用旧实现，但新二进制的原生行为须重新测试。

回滚：退出新候选后使用保留的r10，SQLite保持schema1，无破坏性迁移；r10忽略新增布局文件及用户新增架仍由原Store可读。不得删除数据库/来源/旧包；布局不兼容时保留原文件，不静默降级覆盖。未安装、未发布稳定版、未自动合并。
