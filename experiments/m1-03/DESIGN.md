# M1-03 比较约束

本文件约束实验，不批准最终设计系统。模式：Operate。

- 两套方案分别继承固定版本 SpaceUI 和 shadcn/ui 的组件语法、间距、圆角与状态，保留来源许可；不另做概念方向或图片提案。
- 使用同一 React 信息结构、合成素材生成器、1120×760 初始逻辑尺寸、500/2000 项、同一虚拟列表及 pointer 排序实现。
- 导航在左、文件内容在中，Inspector 默认关闭；宽窗可固定右侧详情，小窗用抽屉。共用蓝色强调色、中文系统字体、无远程字体或图片。
- 原型功能包括网格/详细列表、缩略图尺寸、标签页、搜索、分组折叠、标签过滤、右键、预览、选中后工具栏及键盘操作；不删除或复制真实用户文件。
- 技术比较入口与样本状态明确可见，主要素材区域保持用于整理文件的密度，避免把探针控制铺成仪表盘。
- 以一次批量视觉检查和最多一次修正复查收尾；性能和交互回归独立记录。
